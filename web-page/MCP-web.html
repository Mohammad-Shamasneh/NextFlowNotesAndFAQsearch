Model Context Protocol (MCP) is an open standard that lets an AI model like Claude call external tools through one consistent interface, instead of every app wiring up its own custom integration. This server speaks MCP over stdio and exposes the tools below — every input is checked against a strict Zod schema before it ever touches a file.
