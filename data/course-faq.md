# Course FAQ

## Frequently Asked Questions

### How do I submit my project?

Push your latest code to GitHub and submit the repository link through the course portal.

### Can I work in a team?

Yes. Teams consist of two students.

### Is Internet required on Demo Day?

No. The project should continue working using local data if Wi-Fi is unavailable.

### Which file types are supported?

The server currently supports Markdown (.md) files.
