# Project FAQ

## What does this MCP server do?

It helps users search, read, create, and update Markdown notes stored locally.

## Does it require an Internet connection?

No. The project works completely offline using local Markdown files.

## Which tools are available?

- list_notes
- search_notes
- read_note
- add_note
- update_note

## Where are notes stored?

All notes are stored inside the data directory.
